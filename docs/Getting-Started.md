# Getting Started

## Installation

Open-QuizUI is installed through Open WebUI's Tools and Functions pages.

### Tool

1. Download or copy [quiz_tool.py](https://github.com/axel-chamberland/Open-QuizUI/blob/main/src/openquizui/quiz_tool.py).
2. Open **Workspace → Tools** in Open WebUI.
3. Create a new function and paste the Open-QuizUI code.
4. Save the function and enable it.
5. Some features may require you to enable iframe Sandobx Allow Same Origin: **Settings → Interface → iframe Sandbox Allow Same Origin**

### Function

1. Download or copy [quiz_function.py](https://github.com/axel-chamberland/Open-QuizUI/blob/main/src/openquizui/quiz_function.py).
2. Open **Admin Panel → Functions** in Open WebUI.
3. Create a new function and paste the Open-QuizUI code.
4. Save the function and enable it. To enable it globally, select **`...` → `Global`**.
5. Some features may require you to enable iframe Sandobx Allow Same Origin: **Settings → Interface → iframe Sandbox Allow Same 

## Configuration

Open the function/tool's settings in Open WebUI to configure the available options.

It is recommended to enable **MathJax** to display mathematical/latex expressions properly (turned off by default as it requires internet to load the MathJax library). All quiz content remains private.
