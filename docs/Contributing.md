# Contributing

Bug fixes, tests, improvements, documentation, and new features are welcome.

For larger changes, consider opening an issue first to discuss the proposed change.

## Code Contributions

For code changes:

1. Fork the repository.
2. Create a branch for your changes.
3. Make and test your changes locally.
4. Push the branch to your fork.
5. Open a pull request against the main repository.

When submitting a pull request:

* Clearly describe what was changed.
* Explain any relevant implementation decisions.
* Add or update tests when appropriate.
* Run the test suite before submitting the pull request.

## Documentation/Wiki Contributions

For small documentation changes, open an issue describing the suggested change.

For larger documentation changes, you can clone the repository, make your changes in `docs/`, and open a pull request:

```bash
git clone https://github.com/axel-chamberland/Open-QuizUI.git
cd Open-QuizUI
```

Make your changes in the `docs/` directory, then submit them through a pull request for review.
